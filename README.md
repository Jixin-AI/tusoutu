# 图搜图软件

Windows 本地桌面程序，用于同步花型文件、转换 JPG、按整图或局部图片搜索，并显示原文件名、所在路径和耗时。

## 当前功能

- 递归扫描 TIFF、JPG、PNG、PDF、AI；忽略其他格式，转换结果写入独立 JPG 文件夹，不修改源文件。
- 栅格图片保留像素宽高，只把 JPG 分辨率设为 72 DPI。PDF 按页以 72 DPI 输出；AI 仅支持含 PDF 兼容内容的文件。
- 自动监测间隔可设为 1 小时至 7 天；监测在软件运行期间进行。新增、修改和删除源文件时，同步转换 JPG 库。
- 上传或粘贴查询图片，可裁剪局部；搜索范围可选整个图库或任意子文件夹；相似度门槛可设为 1%–100%。
- 每个文件显示转换耗时；搜图过程与完成状态显示搜索耗时。

## 运行

使用 Python 3.11 或更新版本，并先在 Windows 安装 libvips 运行库、将其 bin 目录加入 PATH。然后在项目目录执行：

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

首次选择花型库后，程序会在同级创建 `<花型库名>_JPG` 文件夹。索引数据库保存在 JPG 库中。
